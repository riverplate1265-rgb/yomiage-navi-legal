1はじめに

本プライバシーポリシー（以下「本ポリシー」）は、Riverplate Studio（以下「当方」）が提供するAndroidアプリ「予定読み上げナビ」（以下「本アプリ」）における、利用者情報の取り扱いについて定めるものです。本アプリをご利用いただく際は、本ポリシーに同意いただいたものとみなします。

本アプリは、カレンダーに登録された予定を指定した時刻に音声で読み上げるリマインダーアプリです。予定の読み取りと読み上げが機能の中心であるため、以下ではカレンダー情報・音声合成・広告・課金に関する取り扱いを中心に説明します。

4情報の保存場所・保存期間

予定の内容、選んだ読み上げタイミング、声の設定、購入状態などは、すべて端末内のローカルデータベース（SQLite）にのみ保存されます。アプリをアンインストールする、または端末のアプリデータを消去すると、これらの情報は端末から失われます。これらについて、当方はサーバー側に保存を行いません。

音声合成時に送信する文章について

有料プラン「高品質な声」をご利用の場合のみ、読み上げ文（最大500文字程度）を当方が運用するサーバー（Google Cloud Functions）経由でGoogle Cloud Text-to-Speech APIへ送信し、音声データを生成します。このサーバーは送信された文章を保存せず、音声合成の処理が終わり次第、文章はメモリ上から破棄されます。生成された音声データ（mp3）は端末内にのみキャッシュされます。あわせて、購入済み・無料トライアル中のいずれかであることを確認するため、端末の識別子（Android ID）と購入者ID（RevenueCatのアカウント識別子）も同じリクエストで送信されます。これらは判定のみに使われ、サーバー側に保存されることはありません（Android IDについては、無料トライアルの記録として次項のとおり別途保持されます）。

無料トライアルの開始時刻について

無料トライアル（14日間）は、アプリの再インストールによって繰り返し取得できてしまわないよう、開始時刻を端末内ではなく当方のサーバー（Google Cloud Functions・Firestore）に記録します。記録するのは「端末の識別子（Android ID）」と「初回アクセス時刻」のみで、氏名・メールアドレスなど個人を特定できる情報とは紐づけません。この記録は、不正なトライアル取得を防ぐという目的上、他の情報とは異なりサーバー側に保持し続けます。

5第三者への提供・委託

本アプリは、機能の提供にあたり次の外部サービスを利用しています。各サービスにおける情報の取り扱いは、それぞれのプライバシーポリシーに従います。

  • Google（Google Calendar API / Googleサインイン / Google Cloud Text-to-Speech / Google AdMob / Google Play課金） — https://policies.google.com/privacy
  • RevenueCat, Inc.（購入状態の管理） — https://www.revenuecat.com/privacy

上記以外の目的で、取得した情報を第三者に販売・提供することはありません。

6広告について

無料プランのご利用時、Google AdMobによるバナー広告を表示します（有料プランをご購入いただくと広告は表示されなくなります）。AdMobは広告の配信・効果測定のため、広告識別子（Advertising ID）や端末情報などを収集する場合があります。詳細はGoogleの広告に関するポリシーをご確認ください。

7課金について

有料プラン（買い切り）の決済は、Google Playの課金システムを通じて行われます。当方は購入状態の管理にRevenueCatのサービスを利用しており、匿名の購入者IDと購入履歴（商品ID・購入日時等）が同社に送信されます。クレジットカード情報などの決済情報自体は当方には共有されません。

9お子様のプライバシー

本アプリは13歳未満のお子様を主な対象としていません。当方は、13歳未満のお子様から意図的に個人情報を収集することはありません。

10開示・削除等のご請求

本アプリが取り扱う情報の大部分は端末内にのみ保存されているため、アプリのアンインストールまたはアプリデータの消去により、基本的にすべての情報が削除されます。それ以外に開示・削除等をご希望の場合は、12章の連絡先までお問い合わせください。内容を確認のうえ、合理的な期間内に対応します。

11本ポリシーの変更

法令の改正やサービス内容の変更等に伴い、本ポリシーを予告なく変更することがあります。重要な変更を行う場合は、アプリ内または本ページにて周知します。変更後の本ポリシーは、本ページに掲載した時点から効力を生じます。
